# 明星数据集目录

本目录存放明星原始照片与构建出的特征库。**照片与特征库均不入库 Git**
（体积大且含人脸数据，仅在本机使用）。

## 目录结构

```
data/
├── faces/               # 原始照片，按姓名分文件夹
│   ├── 周杰伦/
│   │   ├── 001.jpg
│   │   ├── 002.jpg
│   │   └── ...
│   ├── 林俊杰/
│   │   ├── 001.jpg
│   │   └── ...
│   └── ...
└── star_features.pkl    # build_db.py 生成的 512 维特征库（不入库）
```

## 数据来源建议

1. **104 位明星人脸识别数据集**：百度 AI Studio / GitHub 搜索获取，
   规模小，适合 MVP 快速启动。
2. **自行收集**：每位明星 10~20 张不同角度、不同妆容的照片，
   可从公开剧照、海报、访谈截图整理（注意版权，仅供个人学习）。
3. **后续扩展**：CN-Celeb 数据集（规模大，需筛选中国明星子集）。

## 照片质量要求

- 人脸清晰、尽量正脸或半侧脸；
- 光线均匀、无严重遮挡（口罩/墨镜）；
- 每人照片风格多样化（不同发型、年龄段），提高泛化能力。

## 构建特征库

```bash
cd backend
python build_db.py            # 默认读取 ../data/faces，输出 ../data/star_features.pkl
python build_db.py --data-dir ../data/faces --min-images 5   # 自定义参数
```

构建完成后重启识别服务即可生效：

```bash
python app.py
```
